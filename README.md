# 🛡️ Shield Up!

¡Bienvenido al repositorio oficial de **Shield Up!** Este es un proyecto colaborativo enfocado en el desarrollo de mecánicas de juego dinámicas, optimización y diseño de niveles.

---

## 🎮 Sobre el Juego
**Shield Up!** es un videojuego en desarrollo donde la estrategia, los reflejos y la gestión de defensas son clave para sobrevivir. 

* **Género:** Arcade / Estrategia / Acción
* **Plataforma:** PC
* **Entorno de Desarrollo:** Processing / Apache Netbeans

---

## 🚀 Características Principales
* 🛡️ **Sistema de Escudos Avanzado:** Mecánicas de colisión y defensa en tiempo real.
* 👾 **Enemigos Dinámicos:** Oleadas de desafíos con velocidad y patrones variables.
* ⚡ **Optimización de Rendimiento:** Código estructurado para mantener una tasa de FPS fluida.
* 📊 **Interfaz Limpia:** HUD intuitivo para monitorear la vida, el escudo y la puntuación.

---

## 🛠️ Cómo Ejecutar el Proyecto

Para probar el juego de forma local en tu computadora, sigue estos pasos:

1. **Clona o descarga el repositorio:**
   * Haz clic en el botón verde **Code** arriba a la derecha y selecciona *Download ZIP* (o usa `git clone` si manejas la terminal).
2. **Descomprime el archivo** (si lo descargaste en .zip).
3. **Abre el entorno de desarrollo** (Processing para Modulo 1 y Apache Netbeans para Modulo 2).
4. **Importa la carpeta del proyecto** y busca el archivo principal (ej: `.pde` o `.java`).
5. ¡Dale al botón de **Ejecutar/Play** y a jugar!
